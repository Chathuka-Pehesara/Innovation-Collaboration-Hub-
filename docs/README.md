## 🎯 Project Overview

**Innovation Collaboration Hub** is an open-source platform connecting students, researchers, and innovators across campus departments (AI, Cybersecurity, IT & Networks, Software Engineering).

### 🌟 Core Capabilities
- **Multidisciplinary Squad Matching**: Match skills across departments for hackathons and research initiatives.
- **Real-Time SOC & Threat Intelligence**: Live threat auditing, bot interception, and cryptographic proof-of-work shielding.
- **Commit & Contribution Analytics**: Track active code contributions, additions/deletions, and member leaderboards.
- **Live Network Topology**: Visual monitoring of active microservices, latency, and telemetry.
